# ₹100 Indian Rupee Notes

Place all ₹100 note variants in this folder.

## Recommended Images:
- `main.jpg` - Best quality ₹100 note (primary reference)
- `variant1.jpg` - Different lighting condition
- `variant2.jpg` - Slightly worn condition
- `old_series.jpg` - Old design series (if available)
- `new_series.jpg` - New design series (if available)

## Image Requirements:
- **Resolution:** 1200x600+ pixels
- **Format:** JPG, JPEG, PNG, WEBP
- **Quality:** Sharp, clear, good lighting
- **Orientation:** Horizontal preferred

## Expected Accuracy:
- 1 image: 60-70%
- 2-3 images: 80-85%
- 4-5 images: 85-92%
- 6+ images: 90-95%

Add your ₹100 note images here and restart the server to load them.
