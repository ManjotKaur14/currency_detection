# Reference Notes Directory

Place high-quality reference currency images here with the following naming convention:

## Filename Format
`{CURRENCY_CODE}_{DENOMINATION}.jpg`

## Examples
- `INR_10.jpg` - Indian ₹10 note
- `INR_100.jpg` - Indian ₹100 note
- `USD_20.jpg` - US $20 bill
- `EUR_50.jpg` - Euro €50 note

## Image Requirements
- High resolution (300+ DPI recommended)
- Clear, well-lit photography
- Minimal perspective distortion
- JPEG format
- Front side of currency note
